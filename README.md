# Priyanshu Digital Hub — Motion Website

A responsive, single-page digital marketing website with a cinematic motion treatment, glass navigation/footer, scroll reveal, a subtle hero parallax interaction and your four supplied illustrations.

## Preview locally

1. Extract the ZIP package.
2. Keep `index.html` and the `assets/` folder together.
3. Open `index.html` in a modern browser. For best local testing, use a simple static server (for example, VS Code Live Server) so relative assets load consistently.

## Included files

- `index.html` — complete standalone HTML with inline CSS and JavaScript.
- `assets/digital-marketing-overview.png` — supplied digital marketing illustration used in the hero and visual guides.
- `assets/ai-search-ecosystem.png` — supplied AI/SEO/GEO/AEO illustration.
- `assets/seo-aeo-geo-comparison.png` — supplied SEO/AEO/GEO comparison illustration.
- `assets/paid-campaign-management.png` — supplied campaign-management illustration.

## Motion and accessibility

- Hero entrance choreography and soft ambient motion.
- Scroll-triggered reveals and scroll progress indicator.
- Subtle pointer parallax on fine-pointer devices.
- Reduced-motion preferences are respected; content remains visible without JavaScript.
- Responsive layout for desktop, tablet and mobile.

## Before publishing

- Confirm the phone, email, WhatsApp link, office address and opening hours.
- Replace the approximate Agra location and city-centre coordinates with a verified business location only if appropriate.
- Replace founder, certification and results placeholders with genuine evidence; do not publish fictional claims as facts.
- Review the privacy notice and terms for your actual services and data practices.
- Connect the contact form to a real form backend if you want submissions delivered automatically. The current prototype prepares an email draft using the visitor's email application.
- Add your real domain and production social-preview image.

The Alpine video and Nexeus wordmark from the supplied motion-reference prompt were not used: that media and brand identity are unrelated to Priyanshu Digital Hub. The visual motion language was adapted to your existing brand and the marketing illustrations you supplied.
